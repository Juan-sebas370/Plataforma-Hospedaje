┌───────────────────────────────────────────────────────────────────┐
│                  🚀 INICIO RÁPIDO (5 MINUTOS)                    │
└───────────────────────────────────────────────────────────────────┘

PASO 1: Instalar Ollama
   └─ Descargar de https://ollama.ai
   └─ Instalador para Windows, Mac, Linux

PASO 2: Descargar Modelo
   └─ ollama pull mistral
   └─ Esperar ~5GB (primera vez)

PASO 3: Iniciar Ollama
   └─ ollama serve
   └─ Dejar corriendo ✓

PASO 4: Terminal Nueva - Activar Python
   └─ .venv\Scripts\activate   (Windows)
   └─ source .venv/bin/activate (Linux/Mac)

PASO 5: Instalar Paquetes
   └─ cd ollama_api
   └─ pip install -r requirements.txt

PASO 6: Iniciar API
   └─ python main.py
   └─ Vera: "✅ API iniciada en 0.0.0.0:8000"

PASO 7: ¡Probar!
   └─ http://localhost:8000/docs
   └─ http://localhost:4200/chatbot


┌───────────────────────────────────────────────────────────────────┐
│                    🎯 ENDPOINTS DISPONIBLES                       │
└───────────────────────────────────────────────────────────────────┘

🔵 GET /
   └─ Info de la API

🔵 GET /health
   └─ Estado API y Ollama
   └─ Response:
      {
        "api_status": "healthy",
        "ollama_connected": true,
        "timestamp": "2024-01-01T12:00:00"
      }

🔵 GET /models
   └─ Modelos disponibles en Ollama
   └─ Response:
      {
        "models": [
          {"name": "mistral", "modified_at": "..."},
          {"name": "llama2", "modified_at": "..."}
        ]
      }

🟢 POST /chat
   └─ Enviar mensaje al chatbot
   └─ Request:
      {
        "message": "¿Hola, cómo estás?",
        "model": "mistral",
        "session_id": "opcional"
      }
   └─ Response:
      {
        "response": "Respuesta de la IA...",
        "model": "mistral",
        "timestamp": "2024-01-01T12:00:00",
        "session_id": "id_sesion_123"
      }

🔵 GET /chat/{session_id}
   └─ Obtener historial de sesión
   └─ Response:
      {
        "session_id": "id_sesion",
        "created_at": "2024-01-01T10:00:00",
        "model": "mistral",
        "messages": [
          {"role": "user", "content": "...", "timestamp": "..."},
          {"role": "assistant", "content": "...", "timestamp": "..."}
        ]
      }

🔴 DELETE /chat/{session_id}
   └─ Eliminar una sesión

🔵 GET /chat/sessions
   └─ Obtener todas las sesiones

┌───────────────────────────────────────────────────────────────────┐
│                    🐛 TROUBLESHOOTING RÁPIDO                     │
└───────────────────────────────────────────────────────────────────┘

❌ "No se puede conectar con Ollama"
   ✓ Ejecutar: ollama serve
   ✓ Verificar: http://localhost:11434/api/tags

❌ "Modelo no encontrado"
   ✓ Descargar: ollama pull mistral
   ✓ Listar: ollama list

❌ "Puerto 8000 en uso"
   ✓ Cambiar en .env: API_PORT=8001
   ✓ O matar proceso: taskkill /PID xxxx /F

❌ "CORS error en navegador"
   ✓ Verificar CORS_ORIGINS en .env
   ✓ Asegurar que incluya http://localhost:4200

❌ "API timeout"
   ✓ Modelo lento (usar uno más pequeño)
   ✓ Aumentar timeout en requests
   ✓ Usar main_streaming.py para WebSocket
