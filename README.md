# HOSPEDJE SEBASTIAN

Sistema de gestión hotelera desarrollado con Angular y Node.js

## 🏗️ Estructura del Proyecto

```
HOSPEDJE-SEBASTIAN/
├── frontend/          # Aplicación Angular
├── backend/           # API Node.js + Express
└── README.md
```

## 🚀 Tecnologías

### Frontend
- Angular 17+
- TypeScript
- Bootstrap / Tailwind CSS

### Backend
- Node.js
- Express
- MongoDB / PostgreSQL

## 📦 Instalación

### Frontend
```bash
cd frontend
npm install
ng serve
```

### Backend
```bash
cd backend
npm install
npm run dev
```
