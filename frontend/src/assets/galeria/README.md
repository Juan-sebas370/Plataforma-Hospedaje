# Imagenes de la Galeria

Coloca aqui las fotos nuevas que quieras mostrar en la pagina Galeria.

## Nombres recomendados

- fachada.jpg
- sala-estar.jpg
- cocina.jpg
- mezanine.jpg
- habitacion-101.jpg
- habitacion-102.jpg
- habitacion-103.jpg
- habitacion-201.jpg
- habitacion-202.jpg
- habitacion-203.jpg
- habitacion-204.jpg

Usa nombres en minusculas, sin tildes ni espacios. Para agregar una imagen a la interfaz, registra su ruta en:

`frontend/src/app/components/galeria/galeria.ts`

La ruta de una imagen guardada aqui se escribe asi:

`assets/galeria/fachada.jpg`
