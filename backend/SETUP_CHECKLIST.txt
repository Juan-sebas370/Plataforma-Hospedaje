🎯 CHECKLIST RÁPIDO (30 MINUTOS PARA EMPEZAR)

Paso 1: IMPORTAR EN POSTMAN (2 min)
  ☐ Abre Postman
  ☐ Click: File → Import
  ☐ Selecciona 5 archivos .json:
    • Hospedaje_Sebastian_API_v2.postman_collection.json
    • Hospedaje_Sebastian_Environment.postman_environment.json
    • Hospedaje_Sebastian_Staging.postman_environment.json
    • Hospedaje_Sebastian_Production.postman_environment.json
    • Hospedaje_Sebastian_Globals.postman_globals.json
  ☐ Importados! ✅

Paso 2: VERIFICAR BACKEND (2 min)
  ☐ Backend debe correr en: http://localhost:3000
  ☐ Prueba: curl http://localhost:3000/api/health
  ☐ Debe responder: { "status": "ok" }

Paso 3: CONFIGURAR ENTORNO LOCAL (2 min)
  ☐ Top izquierda: Selecciona "Hospedaje_Sebastian_Environment"
  ☐ Verifica que base URL sea: http://localhost:3000/api

Paso 4: EJECUTAR UN ENDPOINT (5 min)
  ☐ Ve a carpeta "Health Check"
  ☐ Click en "GET /health"
  ☐ Click en "Send"
  ☐ Espera respuesta (200 OK)

Paso 5: EJECUTAR COLECCIÓN COMPLETA (10 min)
  ☐ Click derecho en colección
  ☐ "Run collection"
  ☐ Click en "Run Hospedaje_Sebastian_API_v2"
  ☐ Espera a que terminen todos los tests
  ☐ Revisa resultados (verde = ✅ pasó)

Paso 6: GENERAR REPORTE (5 min)
  ☐ [WINDOWS] Terminal: .\run-tests.bat
  ☐ [LINUX/MAC] Terminal: bash run-tests.sh
  ☐ Se abre automáticamente el reporte HTML

💡 CONSEJOS PROFESIONALES

1. Variables automáticas disponibles en tests:
   {{$randomEmail}}        → email@example.com
   {{$randomFirstName}}    → John
   {{$randomLastName}}     → Doe
   {{$randomInt}}          → 42
   {{$randomPrice}}        → $42.50

2. El login guarda automáticamente:
   {{authToken}}           ← Para autorización
   {{userId}}              ← ID del usuario logueado

3. Cada request guarda variables automáticamente:
   {{reservaId}}           ← ID de reserva creada
   {{habitacionId}}        ← ID de habitación
   {{codigoConfirmacion}}  ← Código generado

4. Ejecutar solo una carpeta:
   newman run collection.json --folder "🔐 Autenticación"

5. Ver más detalles en tests:
   newman run collection.json --verbose
