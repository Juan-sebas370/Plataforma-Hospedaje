🆘 SOPORTE Y TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

Si tienes problemas:

1. Lee: COMIENZA_AQUI.txt
2. Ejecuta: python verificador.py
3. Revisa: ollama_api/README.md (Troubleshooting)
4. Mira los logs en la terminal donde corre la API

Problemas comunes:
  • "No se conecta con Ollama" → ollama serve en otra terminal
  • "Puerto ocupado" → Cambiar API_PORT en .env
  • "Modelo no encontrado" → ollama pull mistral
  • "CORS error" → Verificar CORS_ORIGINS en .env
